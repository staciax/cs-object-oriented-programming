# Object Oriented Programming in C++

This repository showcases practical code examples and assignments from my second-year Object Oriented Programming course. Throughout the semester, I worked through various OOP concepts and implemented them in C++.

## Repository Structure

Each folder represents a different topic we covered in class, containing hands-on examples and exercises that helped me understand these fundamental programming concepts:

1. **Object Oriented Programming Concepts** 
2. **Classes and Objects** 
3. **Dynamic Objects and Arrays of Objects** 
4. **References** 
5. **Class Relationships**
6. **Single Inheritance**
7. **Multiple Inheritance** 
8. **Operator Overloading** 
9. **Other Member Functions**
10. **Polymorphism and Virtual Functions**
11. **Templates**
12. **Exception Handling**
